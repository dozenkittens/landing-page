**Часть 1. Выбор референса и планирование**

**Задание 1.1. Выбор референса**

Для разработки статического лендинга был выбран референс «Zello - Corporate Institutional OnePage», опубликованный на платформе Behance.

Ссылка на проект: [https://www.behance.net/gallery/257406757/Zello-Corporate-Institucional-OnePage/modules/1503251349](https://www.behance.net/gallery/257406757/Zello-Corporate-Institucional-OnePage/modules/1503251349)

Референс представляет собой корпоративный одностраничный сайт страховой компании. Дизайн выполнен в современном минималистичном стиле с использованием контрастных светлых и тёмных секций, фотографий, крупных заголовков и золотистых акцентов.

**Задание 1.2. Список секций лендинга**

В выбранном дизайне выделены следующие секции:

1. Header - шапка сайта с логотипом и навигационным меню.
2. Hero - главный экран с заголовком, описанием, изображениями и кнопкой      связи.
3. About - информация о компании и её основателе, миссия, видение и      ценности.
4. Services - блок с карточками страховых услуг.
5. Statistics and Partners - статистические показатели и логотипы      компаний-партнёров.
6. FAQ - секция часто задаваемых вопросов.
7. Contact - контактная информация и форма связи.
8. Footer - нижняя часть сайта с логотипом, контактами и ссылками на      социальные сети.

**Задание 1.3. Цветовая палитра и шрифты**

В дизайне используются следующие основные цвета:

- Чёрный (#111111) - фон тёмных секций.
- Белый (#FFFFFF) - фон светлых секций и карточек.
- Золотистый (#EABB3F) - акцентный цвет для кнопок и выделения текста.
- Светло-серый (#F3F3F3) - дополнительный цвет фона.

Для заголовков используется шрифт с засечками (Serif), для основного текста - шрифт без засечек (Sans-serif).

В качестве приближённых аналогов планируется использовать Georgia для заголовков и Arial для основного текста.

# Часть 2. Создание и настройка проекта

**Задание 2.1. Создание проекта**

Для разработки лендинга был создан проект с использованием Next.js и TypeScript.

При создании проекта были выбраны следующие параметры:
- Next.js - основной фреймворк.
- TypeScript - язык программирования.
- App Router - система маршрутизации.
- CSS Modules - способ подключения стилей.

**Задание 2.2. Структура проекта**

Для удобства разработки файлы проекта были распределены по отдельным папкам:

- `app` - основные файлы приложения.
- `components` - компоненты сайта.
- `docs` - скриншоты готового проекта.

В папке `components` созданы следующие компоненты:

1. Header - шапка сайта.
2. Hero - главный экран.
3. Features - основные информационные секции.
4. Footer - нижняя часть сайта.

Для каждого компонента создан отдельный CSS Module файл.

**Задание 2.3. Настройка проекта**

После создания проекта были выполнены следующие действия:

1. Настроены глобальные стили сайта.
2. Подключены CSS Modules.
3. Настроены основные параметры страницы.
4. Подготовлены компоненты для дальнейшей разработки лендинга.

В процессе разработки были настроены:

# Часть 4. Адаптивная вёрстка

**Задание 4.1. Настройка адаптивности**

Для корректного отображения сайта на разных устройствах была реализована адаптивная вёрстка с помощью CSS Media Queries.

Были учтены следующие размеры экранов:

- 375 px - мобильные устройства.
- 768 px - планшеты.
- 1440 px - компьютеры и ноутбуки.

**Задание 4.2. Адаптация элементов сайта**

При настройке адаптивности были выполнены следующие изменения:

1. Настроено изменение размеров заголовков и текста.
2. Изменено расположение блоков для небольших экранов.
3. Настроено отображение карточек услуг.
4. Скорректированы отступы между секциями.
5. Настроено отображение навигации на мобильных устройствах.
6. Проверено отображение изображений на разных разрешениях.

**Задание 4.3. Проверка адаптивности**

После завершения вёрстки сайт был проверен в браузере с помощью инструментов разработчика.

Проверка проводилась на трёх разрешениях экрана: 375 px, 768 px и 1440 px.
